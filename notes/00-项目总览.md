# 项目总览：基于错题知识库的智能问答助手

## 一句话定位
一个面向学习复盘场景的 AI 应用：用户录入错题，系统建立语义检索索引，
通过 RAG + Agent 实现智能问答、错因分析、相似题推荐。

## 技术栈
- **后端**：Python 3.11 / FastAPI / Pydantic
- **数据库**：MySQL（核心数据）/ Redis（会话）
- **向量检索**：FAISS（+ LangChain 封装）
- **AI**：千问（对话 + Embedding）
- **框架**：LangChain / LangGraph
- **协议**：REST + SSE

## 分层架构

api/ → HTTP 接口层，只负责请求/响应
services/ → 业务逻辑层
repositories/ → 数据访问层（MySQL + Redis）
models/ → SQLAlchemy ORM 模型
schemas/ → Pydantic 请求/响应模型
ai/ → LLM、Embedding、检索、Prompt、工具、Agent
core/ → 数据库连接、日志、异常、重试

## 核心请求链路

用户提问
↓
① Redis 读会话历史
↓
② LLM 改写问题（有历史时）
↓
③ FAISS 语义检索 Top-K 错题
↓
④ 拼 Prompt（历史 + 检索结果 + 问题）
↓
⑤ LLM 生成回答（或调工具）
↓
⑥ Redis 写回会话
↓
返回 reply + references## 三个存储的职责
| 存储  | 存什么       | 特点                      |
| :---- | :----------- | :------------------------ |
| MySQL | 错题完整数据 | 强持久化、事务            |
| Redis | 会话历史     | 内存级、TTL 过期          |
| FAISS | 向量索引     | 语义检索、可从 MySQL 重建 |
